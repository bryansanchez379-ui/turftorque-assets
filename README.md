# Sector 5 RP - public assets

Public image assets for the Sector 5 RP FiveM server listing.

| File | Used for |
|---|---|
| `s5-banner-detail.png` | `sets banner_detail` - server listing detail view (1920x1080) |
| `s5-banner-connecting.png` | `sets banner_connecting` - connection screen (1920x1080) |

These are referenced directly from `server.cfg` via raw.githubusercontent.com, so the
URLs must stay stable. **Do not rename, move, or delete these files** - doing so breaks
the server listing. Replace in place to update the artwork.
